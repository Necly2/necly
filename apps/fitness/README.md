# Necly Fitness (личный учебный проект)

Личное фитнес + питание приложение для iPhone. Flutter, офлайн-first, **без платных
подписок**. Вдохновлено Lyfta/Feeel, но весь код свой, а данные — из открытых
источников (wger, Open Food Facts). **Не для публикации и не для монетизации.**

## Что оно должно уметь
1. Логировать каждую тренировку — что и как сделал (подходы, повторы, вес, время).
2. 🔑 Показывать **нагрузку на каждую группу мышц — бесплатно** (в Lyfta платно).
3. Импортировать тренировки из Lyfta/других приложений через **CSV**.
4. Учёт питания со сканированием **штрих-кода** (Open Food Facts), с учётом регионов.
5. Экспорт всего в **CSV** — чтобы анализировать тренировки + питание в другом
   проекте Claude.

## Как запустить у себя (нужен Mac для iOS)
❗ **Собрать и запустить на iPhone можно только на macOS с Xcode** — это требование
Apple, обойти его в Linux-облаке нельзя. План:

1. На Mac установить **Flutter SDK** и **Xcode**.
2. В папке `apps/fitness/` (полная инструкция — в `docs/IOS_SETUP.md`):
   ```bash
   flutter create --platforms=ios,android --project-name necly_fitness .
   flutter pub get
   dart run build_runner build --delete-conflicting-outputs  # database.g.dart
   dart test                     # юнит-тесты (нагрузка, CSV) — без симулятора
   flutter run                   # запуск в симуляторе iPhone
   ```
   ⚠️ `flutter create` нужен, потому что папки `ios/`/`android/` не лежат в репо
   (их генерирует Flutter). Он не трогает `lib/`, `pubspec.yaml`, `assets/`.
   После него добавь разрешение камеры — см. `docs/IOS_SETUP.md` шаг 2.
3. Для установки на свой физический iPhone нужен бесплатный Apple ID
   (приложение придётся переподписывать раз в 7 дней) или платный Apple Developer
   ($99/год) для постоянной установки.

### Если Mac'а нет
Варианты (не проверял лично — 🔸 уточни условия):
- Codemagic / Bitrise — облачная CI-сборка Flutter под iOS.
- «Облачный Mac» (MacStadium и т.п.) — аренда macOS.
- Запускать под **Android** (тогда нужен только Linux/Windows + Android SDK) —
  быстрее начать, та же кодовая база.
