# История изменений — PVZ Avito для Windows

## Сборка 58 — 11.11.2026

- Программа переименована в **PVZ Master**: новая иконка, установщик PVZ-Master-Setup.exe (ярлыки в «Пуске» и на рабочем столе). Настройки, пресеты и входы на сайты сохраняются.
- Новый интерфейс-мастер: главный экран «Начать выгрузку» → выбор источников (Циан, Авито, Winner) и проверок (Ozon, Яндекс Маркет, Wildberries) → шаги по каждому сайту с вашими вводными вверху → «Выгрузка и проверка». Цвета площадок, анимации переходов.
- Проверка зон запускается только кнопкой «Начать проверку» после выгрузки; «Продолжить проверку» и «Попробовать снова»; ошибки и итоги — окном по центру экрана.
- Авито: этаж «Только первый / Не подвал / Не цоколь» — в списке того, что выставить на сайте (запоминается).
- Новые разделы: «Результаты» (таблица и карта подходящих помещений), «История» (запуски и журнал ошибок с кнопкой «Скопировать для Claude»), «Расписание» (задания по времени, трей, автозапуск, уведомления).
- Числа с разделителями разрядов везде: в полях ввода, статусах, таблицах и Excel.
- Прежние вкладки сайтов — в «Ручном режиме» для опытных.

## Сборка 56 — 11.11.2026

- Исправлено автообновление: «Обновить сейчас» больше не закрывает программу впустую. Обновление скачивается в папку данных программы и подхватывается при перезапуске — без внешних скриптов и без замены файлов самой программы (на Windows и Mac).

## Сборка 55 — 11.11.2026

- Проверка зон: кроме Ozon — Яндекс Маркет и Wildberries (переключатели во вкладке «Проверка»). Логика перенесена из проектных скриптов yandex_pvz_check.py и wb_pvz_check.py.
- Результат — свои файлы на каждую выгрузку: ЯНДЕКС <имя>.xlsx и WB <имя>.xlsx с листами «Результат» и «Исключённые» (с причиной), цвета зон и «Открыть объявление» — как раньше.
- Карточка на главном экране переименована в «Проверка зон».

## Сборка 54 — 11.11.2026

- Новая карточка «Циан и Авито»: параметры поиска задаются в программе — регион, вид помещения, площадь, цена, 1-й этаж, этажность, свежесть.
- Пресеты: сохранить / выбрать / удалить; готовые «Заказ #4 (Москва)» и «Заказ #5 (Москва и МО, до 120 тыс.)».
- Если параметр нельзя задать автоматически (на Авито — вид объекта и площадь), программа заранее предупреждает и при запуске показывает, что именно ввести на сайте; эти фильтры запоминаются в пресете.

## Сборка 53 — 11.11.2026

- Проверка Ozon: переключатель «Запоминать результаты на 3 дня» (включён по умолчанию). Выключите — каждый адрес будет проверяться на карте заново.
- Кнопка «Очистить память» — забыть все запомненные результаты.

## Сборка 52 — 11.11.2026

- Проверка на карте Ozon прямо в программе (Windows и Mac): карточка «Проверка Ozon» / вкладка «Ozon» — список новых выгрузок и кнопка «Проверить на Ozon».
- «Проверять сразу после выгрузки»: файлы с Winner, Циана и Авито сами уходят на проверку, ход виден в строке сверху панели.
- Результат — новый файл на каждую выгрузку (ПРОВЕРКА OZON / Месяц / OZON <имя>.xlsx) с прежним оформлением: цвета зон, «Зона Ozon», «Сверка адреса», «Открыть объявление»; только подходящие зоны, зелёный ≥ 49 м². Дубликаты не ищутся, GENERALIZED не меняется.
- При ограничении запросов Ozon программа ждёт 25 мин и продолжает; результаты по адресам запоминаются на 3 дня.

## Сборка 50 — 11.11.2026

- Версия для Mac (Apple Silicon и Intel): те же Winner, Циан и Авито, тот же интерфейс; автообновление скачивает и подменяет программу сама.
- На Mac работает меню (⌘C / ⌘V / ⌘Q), папки по умолчанию — ~/Desktop/PVZ.

## Сборка 49 — 11.11.2026

- Новый стартовый экран: карточки Baza Winner, Циан и Авито (или клавиши 1 / 2 / 3), номер сборки и проверка обновлений.
- Новый интерфейс панели: тёмная тема, цвет каждого сайта, переключатель сайтов, показываются только нужные для сайта настройки.
- Полоса прогресса выгрузки, итог с зелёной (готово) или красной (ошибка) рамкой.

## Сборка 48 — 11.11.2026

- Добавлен Baza Winner: кнопка «Winner», выгрузка открытого заказа порциями по 300 через мастер экспорта прямо в АДРЕСА\<Месяц>\Адреса ДД[ метка]\export_excel[ метка] ДД N.xlsx — без окна сохранения.
- Настройки мастера экспорта проверяются и исправляются автоматически; каждый файл проверяется (14 колонок, координаты, число строк).
- Режим «в скрытые» (Заказ #3, #5) — скрытие только после проверки записанного файла; режим без скрытия (Заказ #4) — весь заказ, объявления остаются в ленте.

## Сборка 47 — 11.11.2026

- Добавлен Циан: кнопки «Авито» / «Циан» в панели, выгрузка в АДРЕСА ЦИАН\<Месяц>\Циан ДД\export_excel ЦИАН ДД N.xlsx (формат Baza Winner, с координатами).
- Циан: поиск больше ~1 500 объявлений автоматически делится по площади; платные объявления вне фильтров отсеиваются; галочка «только новые» (журнал cian_seen.json); остановка по дате при сортировке «по дате».
- Отдельная папка для Циана в настройках.
