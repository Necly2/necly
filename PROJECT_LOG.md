# PVZ Master — проектный лог (для продолжения в Claude Code)

Состояние на 14.11.2026, последняя опубликованная сборка — **87** (Windows и Mac); «Заказы» — в следующей сборке.
Пользователь: Артём, партнёр Ozon (3 ПВЗ). Пишет по-русски, просит отвечать **коротко, по-русски**, без лишних пояснений.

## 1. Что это
Electron-приложение «PVZ Master» для поиска помещений под ПВЗ:
1. **Выгрузка объявлений** — Циан, Авито, Baza Winner (w7.baza-winner.ru) → Excel-файлы по ≤300 строк.
2. **Проверка зон** каждого адреса — карта Ozon (pvz-map.ozon.ru), опционально Яндекс Маркет и Wildberries.
3. **Результаты** — таблица + карты (Ozon / WB / Яндекс Маркет / Яндекс / 2ГИС / OSM) + сайт объявления; отметки, отслеживаемые, экспорт.

## 2. Репозиторий, сборка, обновления
- GitHub: `Necly2/necly`, рабочая ветка **`avito-windows`** (в ней всё; `main` не используется для приложения).
- `package.json`: `"main": "src/boot.js"`, Electron 45, зависимости только JS (xlsx, exceljs, leaflet, adm-zip, pngjs).
- CI: `.github/workflows/build.yml` — на каждый push:
  - **Windows** (windows-latest): упаковка, Setup.exe, релиз `avito-windows-latest` (zip, Setup.exe, `app.asar`, `version.txt`, `notes.txt`), коммит в CHANGELOG «История изменений: сборка N».
  - **Mac** (macos-latest): .zip через `ditto` (обычный zip ломает симлинки — «формат не поддерживается»), релиз `avito-mac-latest`. Не откатывает, если там уже версия новее.
  - **Mac (обновление)** (ubuntu): запасной путь — копирует `app.asar`/`version.txt`/`notes.txt` из Windows-релиза в Mac-релиз (машины Mac на GitHub бывают недоступны — «not acquired»).
  - Номер сборки = `github.run_number`; версия `1.0.N`.
- **Обновление в приложении** (`src/updater.js` + `src/boot.js`): скачивается только `app.asar` в `userData/updates/app-N.asar`; `boot.js` запускает самую новую. `app.asar` одинаковый для Win и Mac.
- `WHATSNEW.md` — что нового в следующей сборке (строки «- …»), попадает в notes.txt. Дописывать при каждом изменении.
- Коммиты заканчивать строками:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```
- Перед push: `git pull --rebase` (CI коммитит CHANGELOG в ту же ветку).
- Статус сборки: `gh run list -R Necly2/necly -L 3`; Mac-версия: `curl -sL https://github.com/Necly2/necly/releases/download/avito-mac-latest/version.txt`.

## 4. Важные правила и договорённости
- **Baza Winner:** не вводить пароли (пользователь входит сам), не продлевать подписку. Объявления «в скрытые» — только после проверки записанного файла. **Заказ #4 не скрывать.**
- Ozon: пауза по умолчанию 2 с; при 404 (ограничение) — ждать и дозапускать, не долбить.
- Яндекс / WB проверять только если выбраны.
- Зелёная зона: порог площади `ozonGreenMin` (по умолчанию 60 м², берётся большая из мин./макс. площади).
- Настройки проверки читаются **один раз при старте проверки** (изменения — со следующего запуска). Пользователю предложено сделать паузу/потоки «на ходу» — ответа нет.
- Карты в «Результатах» — нативные WebContentsView поверх окна: всё, что всплывает поверх карты (окна, меню «⋯»), должно прятать их через `syncRects()` (условие `away`).
- Координаты для view: CSS-px × `win.webContents.getZoomFactor()` (функция `rb()`); клики в картах — с учётом масштаба сайта.
- Анекдоты про национальности не делать (было отказано; «Только смешные» = лучшие за день anekdot.ru).

## 5. Тесты
- `tools/selftest.sh <dir> <1|0 папки> <dark|light> [FAKE] [EXT] [DEEP]` — запускает приложение под xvfb с `PVZ_*`, скриншоты в `<dir>/shots`, ошибки — строки `RENDERER`/`JSERR` в логе.
- `tools/selftest_data.sh <dir> [theme]` — то же с готовыми данными (история, выгрузка, файл OZON, журнал) из `tools/fixtures`.
- Флаги в `main.js`: `PVZ_FAKE` (тестовые строки), `PVZ_DEEP` (прокликивает результаты/настройки/меню/клавиши/сводку/мастер), `PVZ_EXT`, `PVZ_ZW` (слежение за зонами), `PVZ_OZMAP`, `PVZ_IDLE` (карты без выбранного объявления).
- Нужен `xvfb-run`; WebGL в облаке нет (карта Ozon там не рисуется).
- Не проверено вживую: карта WB (поиск через лупу), сайт 2ГИС, Overpass/МинЖКХ, окошко строки меню Mac, VPN.
