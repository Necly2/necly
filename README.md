# Лента 📰 для Windows

Бегущая строка с заголовками новостей и котировками биржи на экране Windows 10/11.

**Скачать:** [Lenta-Windows.zip](https://github.com/Necly2/necly/releases/download/lenta-windows-latest/Lenta-Windows.zip) · версия для Mac — [здесь](https://github.com/Necly2/necly/releases/tag/lenta-latest)

## Установка

1. Скачайте `Lenta-Windows.zip` (~66 МБ), правый клик → **«Извлечь всё»**.
2. Положите `Lenta.exe` **в свою папку** (например, `Документы\Lenta`), не в `Program Files` — иначе не сработает автообновление.
3. Запустите. Если появится «Windows защитила ваш компьютер» — **«Подробнее» → «Выполнить в любом случае»**.
4. .NET устанавливать не нужно. Иконка появится в трее у часов: **левый клик — настройки, правый — меню.**

## Обновления

- Раз в день «Лента» проверяет GitHub; если есть новая сборка — всплывёт уведомление у часов, нажмите на него → «Да». Программа сама скачает обновление, заменит себя и перезапустится. Вручную: правый клик по иконке → «Проверить обновления…».
- **Нюансы:** `Lenta.exe` должен лежать в папке с правами записи; антивирус может ненадолго задержать замену файла; версии без автообновления один раз заменяются вручную.

## Что умеет

- **Новости** с любого сайта (RSS находится автоматически; без RSS — заголовки со страницы). **Несколько источников сразу**: флажки РБК, Коммерсантъ, Интерфакс, Lenta.ru, ТАСС, Хабр плюс свои сайты через запятую; порядок — по времени вперемешку (с меткой источника) или блоками по источникам. **Клик** по заголовку открывает статью, наведение мыши останавливает строку.
- **Срочные новости**: плашка «СРОЧНО», красное мигание, перемотка к новости, звук. Слова редактируются в настройках.
- **Котировки**: индекс Мосбиржи, акции по тикерам, курсы ЦБ; клик — страница бумаги.
- **Расположение:**
  - сверху экрана или над панелью задач как **закреплённая панель** — развёрнутые окна подстраиваются и не залезают под строку;
  - сверху поверх окон;
  - внизу поверх панели задач.
- Частота кадров: «Как у экрана» (по умолчанию; до 144/165/240 Гц, кадры синхронизированы с монитором) или 30–240.
- Размер, 4 цветовые темы (ТАСС, белый на чёрном, чёрный на белом, белый на тёмно-зелёном), 3 скорости.
- Частота обновления новостей (1–30 мин) и котировок (30 сек – 15 мин).
- «Запускать вместе с Windows».

Настройки хранятся в `%APPDATA%\Lenta\settings.json`.

## Нюансы

- В режиме «закреплённой панели» при запуске игры или видео на весь экран строка уходит на задний план.
- Окно настроек можно растягивать; если не помещается — появляется прокрутка.

## Удаление

Правый клик → «Выйти», снимите автозапуск (если ставили), удалите `Lenta.exe` и `%APPDATA%\Lenta`.
