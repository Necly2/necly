# Сугроб ❄️ для macOS

Снег на рабочем столе Mac: падает поверх экрана, копится сугробами на окнах и Dock, реагирует на мышь и реальную погоду.

**Скачать:** [Sugrob.zip](https://github.com/Necly2/necly/releases/download/sugrob-latest/Sugrob.zip) · версия для Windows — [здесь](https://github.com/Necly2/necly/releases/tag/sugrob-windows-latest)

## Установка

1. Скачайте `Sugrob.zip` и откройте его двойным кликом — появится `Sugrob.app`.
2. **Перетащите `Sugrob.app` в папку «Программы».** Это важно: из «Загрузок» macOS запускает приложение из временной копии, и автообновление не сработает.
3. Запустите. При первом запуске macOS скажет, что не может проверить разработчика — это нормально для приложений без платной подписи Apple:
   - нажмите **«Готово»** (не «В корзину»);
   - откройте **Системные настройки → Конфиденциальность и безопасность**, внизу у строки про Sugrob нажмите **«Всё равно открыть»** и подтвердите паролем или Touch ID.
4. В строке меню появится ❄️. Иконки в Dock у приложения нет.

Требуется macOS 13 или новее, Apple Silicon или Intel.

## Обновления

- Раз в день (и через 15 секунд после запуска) «Сугроб» проверяет GitHub. Если есть новая сборка — спросит «Обновить?», сам скачает её, заменит себя и перезапустится.
- Вручную: ❄️ → **«Проверить обновления…»**. Выключить автопроверку: Настройки → «Обновления».
- Окно «Всё равно открыть» после автообновления больше не появляется.

**Нюансы:**
- Автообновление работает, только если приложение лежит в «Программах» (или другой папке, куда у вас есть права записи).
- Разрешение «Универсальный доступ» (точное положение Dock) после каждого обновления нужно выдать заново: удалите Sugrob из списка кнопкой «−» и добавьте снова. Без него всё работает, просто положение Dock оценивается приблизительно.
- Версии, скачанные до появления автообновления, нужно один раз заменить вручную.

## Что умеет

**Снег и сугробы**
- Снег копится на верхних краях окон и на Dock, холмиками и с комками на верхушке. У скруглённых углов окон снега нет.
- **Дёрнуть окно и резко остановить** — снег слетает по инерции. **Изменить размер** — осыпается. **Закрыть или свернуть окно** — снег падает вниз.
- **Провести курсором по сугробу** — снег сметается. Снежинки расступаются вокруг курсора.
- Mission Control (F3), смена рабочих столов и ⌘H не сбрасывают снег — он прячется и возвращается вместе с окнами.
- Интенсивность: «Почти не идёт», «Редкие снежинки», «Лёгкий снег», «Снегопад», «Метель».
- ❄️ → **«Стряхнуть весь снег»** — порыв ветра случайно влево или вправо сдувает весь снег с окон и Dock за край экрана.

**Погода** (Настройки → «Погода»)
- «Снег всегда» — как раньше. «По погоде в городе» — эффекты по реальной погоде (Open-Meteo, запасной источник — MET Norway, обновление раз в 15 минут):
  - снег → идёт снег, сила зависит от снегопада;
  - дождь → по экрану бьют капли с брызгами, сугробы тают;
  - ясная морозная ночь (−3° и ниже) → края окон покрываются инеем;
  - оттепель (выше +1°) → сугробы постепенно тают.
- Режимы «Дождь» и «Иней» — чтобы посмотреть эффекты, не дожидаясь погоды.
- Город меняется в настройках; текущая погода видна в меню ❄️.

**Снеговик** (Настройки → «Снеговик», по умолчанию выключен)
- Ведите курсором по снегу на Dock **в одну сторону** — снег сгребается в кучу. После 2–3 проходов из неё вырастает снеговик.
- Сколько стоит: до весны (до 1 марта), тает в оттепель, 1 час или до выхода из приложения.
- Наряд: цилиндр, ведро, шапка с помпоном или без шапки. Можно до 1, 3 или 5 снеговиков.
- Кнопки «Слепить снеговика сейчас» и «Убрать всех снеговиков».

**Гирлянда** (Настройки → «Гирлянда», по умолчанию выключена)
- Висит на Dock, вдоль строки меню и/или на окнах. Режимы: плавное мерцание, бегущие огни, случайное мигание, постоянно. 4 палитры, яркость.

**Прочее**
- «Снег за окнами» — снег падает только над рабочим столом.
- «Частота кадров»: «Как у экрана» (ProMotion — 120 Гц, внешние мониторы — до 144/165/240 Гц) или фиксированная 30–240 кадров/с. По умолчанию 60: снег рисуется на весь экран, и высокая частота заметно греет Mac. На паузе приложение ничего не рисует.

## Известные ограничения

- Dock поддерживается только внизу экрана. Без «Универсального доступа» края сугроба на Dock могут не совпасть с Dock на несколько точек.
- Снег рисуется поверх окон в отдельном прозрачном слое; клики проходят сквозь него.

## Удаление

Выйдите через ❄️ → «Выйти» и удалите `Sugrob.app` из «Программ».
