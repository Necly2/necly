# Сугроб ❄️ для Windows

Снег на рабочем столе Windows 10/11: копится сугробами на верхних краях окон и на панели задач.

- Резко дёрнуть окно — снег слетает; изменить размер — осыпается; провести курсором — сметается.
- Закрыть окно — снег падает. «Представление задач» (Win+Tab) и смена рабочих столов снег не сбрасывают.
- Гирлянда: панель задач, верх экрана, окна; 4 режима мигания, 4 палитры, яркость.
- «Сюрприз»: ракета падает в панель задач, снег разлетается и собирается в слово (слово меняется в настройках).
- В полноэкранных играх и видео снег не рисуется.
- Иконка в трее: левый клик — настройки, правый — меню.

Настройки — `%APPDATA%\Sugrob\settings.json`.

## Установка
Скачайте `Sugrob-Windows.zip`, распакуйте, запустите `Sugrob.exe`.
«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
