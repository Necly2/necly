# PVZ Avito + Циан 🏢 для Windows

Программа для проекта PVZ: открывает Авито или Циан в своём окне, по кнопке проходит по страницам текущего поиска и сохраняет объявления в Excel в формате выгрузки Baza Winner (14 колонок, с координатами) — сразу в папку проекта для проверки зон Ozon.

**Скачать:** [PVZ-Avito-Windows.zip](https://github.com/Necly2/necly/releases/download/avito-windows-latest/PVZ-Avito-Windows.zip)

**История изменений:** [CHANGELOG.md](https://github.com/Necly2/necly/blob/avito-windows/CHANGELOG.md) — что добавилось в каждой сборке.

## Установка

1. Скачайте `PVZ-Avito-Windows.zip` (~160 МБ), правый клик → **«Извлечь всё»**.
2. Положите папку `PVZ Avito` **в свою папку вне OneDrive** (например, `C:\Users\<имя>\PVZ Avito` или `Документы`), не в `Program Files` — иначе не сработает автообновление, а OneDrive будет синхронизировать сотни служебных файлов.
3. Запустите `PVZ Avito.exe` (можно сделать ярлык на рабочий стол). Если появится «Windows защитила ваш компьютер» — **«Подробнее» → «Выполнить в любом случае»**.
4. Ничего дополнительно устанавливать не нужно.

## Как пользоваться

1. Кнопками **«Авито» / «Циан»** вверху панели выберите сайт. Справа — обычный сайт: выставьте фильтры заказа (Москва, аренда, вид объекта, площадь, цена, этаж).
2. При первом запуске выберите папки: **АДРЕСА** (для Авито) и **АДРЕСА ЦИАН** (для Циана).
3. Нажмите **«Выгрузить текущий поиск»**. В панели видно страницу, сколько собрано и паузу до следующей страницы; «Остановить и сохранить» — досрочно.
4. Затем скажите Claude «проверить новые адреса».

**Авито:** файлы `АДРЕСА\<Месяц>\Адреса ДД AVITO\avito ДД N.xlsx`.

**Циан:** файлы `АДРЕСА ЦИАН\<Месяц>\Циан ДД\export_excel ЦИАН ДД N.xlsx`.
- Кнопка «Циан» открывает поиск по параметрам заказа №4 (Москва, торговая площадь / общепит / ПСН / бытовые услуги, 24–130 м², 1-й этаж, дом от 3 этажей, сортировка по дате) — его можно поменять прямо на сайте.
- Циан показывает не больше 54 страниц (~1 500 объявлений) на один поиск — если объявлений больше, программа сама делит поиск по площади на части.
- Платные объявления в начале выдачи, которые не подходят под фильтры (площадь, этаж, этажность), отсеиваются.
- Галочка **«только новые»**: уже выгруженные объявления запоминаются в `АДРЕСА ЦИАН\cian_seen.json` и в следующий раз пропускаются.
- При сортировке «по дате» программа останавливается, когда пошли объявления старше заданного числа дней.

Настройки: страниц максимум (на одну часть поиска), пауза между страницами (не меньше 3 с), свежесть объявлений в днях (0 — все), строк в файле.

## Обновления

- При запуске (раз в день) программа проверяет GitHub. Если есть новая сборка — покажет, что нового, и по «Обновить сейчас» сама скачает обновление (~13 МБ), закроется, заменит файл и перезапустится. Вручную: ссылка **«Проверить обновления»** внизу панели. Номер сборки — в заголовке окна.
- **Нюансы:** папка программы должна быть с правами записи (не `Program Files`); антивирус может ненадолго задержать замену файла. Самая первая версия (без автообновления) один раз заменяется вручную.

## Ограничения

- Авито: этаж, подвал и этажность дома в выдаче не указаны — программа их не фильтрует (на Циане фильтруются).
- Цена приводится к рублям в месяц (из «в год», «за м²»).
- Правила Авито и Циана запрещают автоматический сбор; программа ходит медленно и останавливается, если сайт показал проверку на робота (пройдите её в окне справа и повторите позже). Паузу не уменьшайте — иначе возможна блокировка IP.

## Удаление

Удалите папку `PVZ Avito` и `%APPDATA%\pvz-avito` (настройки и куки сайтов).
