# Сугроб ❄️ для Windows

Снег на рабочем столе Windows 10/11: падает поверх экрана, копится сугробами на окнах и панели задач, реагирует на мышь и реальную погоду.

**Скачать:** [Sugrob-Windows.zip](https://github.com/Necly2/necly/releases/download/sugrob-windows-latest/Sugrob-Windows.zip) · версия для Mac — [здесь](https://github.com/Necly2/necly/releases/tag/sugrob-latest)

## Установка

1. Скачайте `Sugrob-Windows.zip` (~66 МБ), нажмите на него правой кнопкой → **«Извлечь всё»**.
2. **Положите `Sugrob.exe` в свою папку**, например `Документы\Sugrob`. Не кладите в `Program Files` — туда программе нельзя писать, и автообновление не сработает.
3. Запустите `Sugrob.exe`. Если появится **«Windows защитила ваш компьютер»** — нажмите **«Подробнее» → «Выполнить в любом случае»**. Это нормально для программ без платной подписи.
4. Устанавливать .NET не нужно — всё внутри одного файла.
5. Иконка ❄️ появится в трее у часов (может быть скрыта под стрелкой ^). **Левый клик — настройки, правый — меню.**

## Обновления

- Раз в день (и через 15 секунд после запуска) «Сугроб» проверяет GitHub. Если есть новая сборка — у часов всплывёт уведомление; нажмите на него → «Да». Программа сама скачает новую версию, заменит себя и перезапустится.
- Вручную: правый клик по ❄️ → **«Проверить обновления…»**. Выключить автопроверку: Настройки → «Обновления».
- Окно «Windows защитила ваш компьютер» после автообновления больше не появляется.

**Нюансы:**
- Автообновление работает, только если `Sugrob.exe` лежит в папке, куда у вас есть права записи (не `Program Files`).
- Антивирус может на секунду задержать замену файла — это нормально.
- Версии, скачанные до появления автообновления, нужно один раз заменить вручную.

## Что умеет

**Снег и сугробы**
- Снег копится на верхних краях окон и на панели задач. Положение окон Windows сообщает точно, скругления углов Windows 11 учитываются.
- **Дёрнуть окно и резко остановить** — снег слетает. **Изменить размер** — осыпается. **Закрыть или свернуть** — падает вниз.
- **Провести курсором по сугробу** — снег сметается. Снежинки расступаются вокруг курсора.
- «Представление задач» (Win+Tab) и смена рабочих столов не сбрасывают снег.
- В полноэкранных играх и видео снег не рисуется.
- Интенсивность: «Почти не идёт», «Редкие снежинки», «Лёгкий снег», «Снегопад», «Метель».
- Меню → **«Стряхнуть весь снег»** — порыв ветра случайно влево или вправо сдувает весь снег за край экрана.

**Погода** (Настройки → «Погода»)
- «Снег всегда» или «По погоде в городе» (Open-Meteo, запасной — MET Norway, раз в 15 минут): снег → снегопад, дождь → капли с брызгами и таяние, ясная морозная ночь → иней на краях окон, оттепель → сугробы тают.
- Режимы «Дождь» и «Иней» — чтобы посмотреть эффекты сразу. Город меняется в настройках, погода видна в меню.

**Снеговик** (Настройки → «Снеговик», по умолчанию выключен)
- Ведите курсором по снегу на панели задач **в одну сторону** — снег сгребается в кучу; после 2–3 проходов вырастает снеговик.
- Сколько стоит: до весны, тает в оттепель, 1 час, до выхода. Наряд: цилиндр, ведро, шапка с помпоном, без шапки. До 1/3/5 снеговиков. Кнопки «Слепить сейчас» и «Убрать всех».

**Гирлянда** (по умолчанию выключена) — на панели задач, по верху экрана и/или на окнах; 4 режима мигания, 4 палитры, яркость.

**Прочее** — «Снег за окнами», «Запускать вместе с Windows», «Частота кадров»: «Как у экрана» (до 144/165/240 Гц) или 30–240 кадров/с. Кадры синхронизированы с монитором. По умолчанию 60 — снег на весь экран при высокой частоте сильнее нагружает компьютер.

Настройки хранятся в `%APPDATA%\Sugrob\settings.json`.

## Известные ограничения

- Поддерживается панель задач внизу экрана.
- При масштабе экрана 125–150% размеры могут немного отличаться от Mac-версии.

## Удаление

Правый клик по ❄️ → «Выйти», снимите галочку автозапуска (если ставили) и удалите `Sugrob.exe` и папку `%APPDATA%\Sugrob`.
