# Лента 📰

Бегущая строка с заголовками новостей под строкой меню macOS.

- Иконка 📰 в строке меню → **«Вставить ссылку на сайт…»**: вставьте адрес сайта (например, https://www.rbc.ru) или прямую ссылку на RSS.
- Приложение само находит RSS-ленту сайта: по ссылке на странице, по списку известных сайтов (РБК, Коммерсантъ, Хабр, РИА, ТАСС, Ведомости…) или по стандартным адресам `/rss`, `/feed`. Если RSS нет, заголовки берутся прямо со страницы.
- Заголовки обновляются каждые 5 минут.
- **⌥ (Option) + клик** по заголовку открывает статью. Без ⌥ клики проходят сквозь полосу, чтобы она не мешала окнам под ней. С зажатым ⌥ строка останавливается под курсором.
- Последние 15 заголовков есть и в меню 📰 → «Последние заголовки».
- Скорость, пауза и скрытие строки — тоже в меню.

## Установка

Скачайте `Lenta.zip` со страницы релиза, распакуйте, перетащите `Lenta.app` в «Программы».
Первый запуск: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

## Сборка вручную

```
./build.sh && open build/Lenta.app
```
