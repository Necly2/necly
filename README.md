# Не спать ☕️ для macOS

Маленькое приложение в строке меню: не даёт MacBook заснуть, когда закрываешь крышку. Включается и выключается одним пунктом в меню.

**Скачать:** [NeSpat.zip](https://github.com/Necly2/necly/releases/download/nespat-latest/NeSpat.zip)

**История изменений:** [CHANGELOG.md](https://github.com/Necly2/necly/blob/nespat/CHANGELOG.md)

## Установка

1. Скачайте `NeSpat.zip`, откройте двойным кликом — появится `NeSpat.app`.
2. **Перетащите `NeSpat.app` в «Программы»** (иначе не сработают автообновление и автозапуск).
3. При первом запуске: **«Готово»** → **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»** → пароль или Touch ID.
4. В строке меню появится 🌙 (обычный сон). Иконки в Dock нет.

Требуется macOS 13 или новее.

## Как пользоваться

Нажмите на иконку → **«Не засыпать при закрытой крышке»**.

- ☕️ чашка — Mac не засыпает, даже с закрытой крышкой и без внешнего монитора;
- 🌙 луна — обычный режим.

**Первое включение** попросит пароль администратора — один раз. Приложение добавит правило `/etc/sudoers.d/nespat`, которое разрешает ему без пароля ровно две команды: `pmset -a disablesleep 1` и `pmset -a disablesleep 0`. Больше ничего.

Ещё в меню:
- **Выключать при заряде ниже 10%** (включено по умолчанию) — чтобы Mac в рюкзаке не разрядился в ноль.
- **Восстанавливать режим при запуске** — если было включено, после перезагрузки/обновления включится снова.
- **Открывать при входе в систему.**
- **Проверить обновления…** — раз в день проверяется само, обновление ставится без переустановки.

## Нюансы

- Экран при закрытой крышке гаснет, а программы, загрузки, музыка и сеть продолжают работать.
- **Не кладите включённый Mac с закрытой крышкой в сумку надолго** — ему негде охлаждаться.
- При выходе из приложения («Выйти») обычный сон возвращается автоматически. Если приложение было принудительно закрыто, а Mac всё равно не засыпает — снова откройте «Не спать» и выключите режим, либо в Терминале: `sudo pmset -a disablesleep 0`.

## Удаление

Выключите режим, нажмите «Выйти», удалите `NeSpat.app` из «Программ». Правило можно убрать в Терминале: `sudo rm /etc/sudoers.d/nespat`.
