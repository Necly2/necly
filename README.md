# Лента 📰 для Windows

Бегущая строка с заголовками новостей и котировками — версия для Windows 10/11.

- Иконка в трее (возле часов): левый клик — настройки, правый — меню.
- Новости с любого сайта (РБК, Коммерсантъ, ТАСС…): RSS находится автоматически.
- Котировки: индекс Мосбиржи, акции, курсы ЦБ.
- Срочные новости: плашка «СРОЧНО», строка мигает красным, звуковой сигнал.
- Расположение: сверху или над панелью задач как «закреплённая панель» (окна не залезают под строку), либо поверх окон / панели задач.
- Клик по заголовку или котировке открывает его в браузере; наведение мыши останавливает строку.
- Автозапуск вместе с Windows — в настройках.

Настройки хранятся в `%APPDATA%\Lenta\settings.json`.

## Установка
Скачайте `Lenta-Windows.zip` со страницы релиза, распакуйте, запустите `Lenta.exe`.
При первом запуске: «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
