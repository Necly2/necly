# Сугроб ❄️

Снег на macOS: копится на верхних краях окон и на Dock.

- **Дёрнуть окно** резко, или резко его остановить: снег слетает по инерции.
- **Изменить размер окна**: снег за новыми краями осыпается, остальное трясётся.
- **Провести курсором** по сугробу на окне или по Dock: снег сметается.
- **Закрыть или свернуть окно**: весь снег с него падает вниз.
- Снежинки расступаются вокруг курсора.

Клики проходят сквозь снег, работать он не мешает.

## Сборка (без Xcode)

1. Установите Command Line Tools, если их ещё нет:
   ```
   xcode-select --install
   ```
2. В Терминале зайдите в папку проекта и соберите:
   ```
   cd ~/Downloads/Sugrob
   chmod +x build.sh
   ./build.sh
   ```
3. Запустите:
   ```
   open build/Sugrob.app
   ```
   В строке меню появится ❄️. Иконки в Dock у приложения нет.

Чтобы приложение лежало постоянно, перетащите `build/Sugrob.app` в «Программы».

## Меню ❄️

- **Снег идёт**: включить или выключить снегопад (лежащий снег остаётся).
- **Лёгкий снег / Снегопад / Метель**: интенсивность.
- **Быстрые сугробы**: снег копится в 5 раз быстрее, удобно для демонстрации.
- **Снег на Dock**: нужен доступ «Универсальный доступ» (см. ниже).
- **Стряхнуть весь снег**, **Пауза**, **Выйти**.

## Снег на Dock

Положение иконок Dock приложение узнаёт через Accessibility API:

1. В меню ❄️ нажмите «Снег на Dock: дать доступ…».
2. В «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» включите Sugrob.
3. Если пункт в меню не сменился на «Снег на Dock», перезапустите приложение.

Поддерживается только Dock внизу экрана.

**Важно:** после каждой пересборки (`./build.sh`) macOS считает приложение новым, и доступ сбрасывается. Удалите Sugrob из списка «Универсальный доступ» кнопкой «−» и добавьте снова.

Остальное (снег на окнах, курсор) работает без каких-либо разрешений.

## Как устроено

| Файл | Что делает |
|---|---|
| `Sources/App.swift` | Запуск, меню в строке меню, таймер 60 кадров/с |
| `Sources/Overlay.swift` | Прозрачное окно поверх каждого экрана, пропускающее клики |
| `Sources/SnowEngine.swift` | Физика: снежинки, сугробы, рывки, ресайз, курсор, отрисовка |
| `Sources/Geometry.swift` | Пересчёт координат, положение Dock через Accessibility |

Рамки окон берутся из `CGWindowListCopyWindowInfo` 30 раз в секунду. По изменению позиции считается скорость окна: резкий скачок скорости означает «бросок».

Что подкрутить в `SnowEngine.swift`:
- `maxHeight`: высота сугроба (18 на окнах, 14 на Dock);
- `2200` в `update(...)`: порог «рывка» (меньше значит снег слетает легче);
- `R: CGFloat = 16` в `brush()`: ширина «щётки» курсора.

## Известные ограничения прототипа

- Собран и проверен на логике, но не запускался на настоящем Mac. Если сборка выдаст ошибку, пришлите её текст.
- Перерисовка всего экрана 60 раз в секунду: на старых Intel-маках может заметно нагружать процессор.
- Скругления углов окон учитываются приблизительно.
- Снег на окне, частично закрытом другим окном, прячется по колонкам, без точной обрезки.
